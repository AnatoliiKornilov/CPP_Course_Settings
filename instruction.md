# Инструкция по настройке репозитория

1. В корень своего репозитория скопируйте файл .clang-format со всем содержимым.

2. В корень своего репозитория скопируйте файл .clang-tidy со всем содержимым.

3. Установите LLVM. На Linux:

```sh
  sudo apt install clang-format clang-tidy
```

4. Если работаете в VSCode, то настройте его, чтобы он мог подсвечивать синтаксис и форматировать файлы. Для этого установите расширения C/C++ и Clang-Format.

5. В корне проекта создайте папку .vscode, в ней файл settings.json. Скопируйте туда содержимое соответствующего файла из этого репозитория. 

6. После этого у вас будут автоматически форматироваться отступы (например, можно нажать на файле правой кнопко мыши и выбрать Format Document или он сам отформатируется после нажатия Ctrl+S).

7. Для проверки файла с помощью clang-tidy выполните команду:

```sh
  clang-tidy -std=c++23 --checks='readability-identifier-naming' ваш_файл.cpp
```

В консоли вам выведутся все ошибки и даже скажут, как исправить.

8. Создайте файл .github/wokflows/cpp-linter.yml и скопируйте туда содержимое соответствущего файла. Теперь при открытии PR у вас будет автоматически запускаться линтер, что гарантирует соблюдение кодстайла.
